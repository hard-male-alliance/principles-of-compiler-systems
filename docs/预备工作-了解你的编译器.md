# 预备工作：了解你的编译器、LLVM IR 与汇编编程

> 小组合作，总分 5 分。

## 任务概览

首先确定上机作业的两人分组。允许跨班组队，但需要向助教备案，之后不应更改。

### 基本要求（4 分）

1. 以 GCC、LLVM/Clang 或其他熟悉的编译工具为研究对象，研究语言处理系统的完整工作过程：
   - 预处理器完成哪些工作。
   - 编译器完成哪些工作，包括编译器内部各阶段的功能。
   - 汇编器完成哪些工作。
   - 链接器完成哪些工作。
2. 熟悉 LLVM IR 中间语言与 ARM 或 RISC-V 汇编语言：
   - 设计一个 SysY 示例程序，覆盖编译器需要支持的语言特性，如数值运算、赋值、条件分支、循环、函数及其他进阶特性。
   - 编写与 SysY 源程序等价的 LLVM IR 程序和 ARM 或 RISC-V 汇编程序。
   - 链接 SysY 运行时库，使用 LLVM/Clang 和汇编器生成目标程序，并验证运行结果。

### 进阶要求（1 分）

观察 AI 编译器 MLIR 中端的处理过程。与基础任务使用的单层 LLVM IR 不同，MLIR 支持多级方言（Dialect）和渐进式降低（Progressive Lowering），可在不同抽象层级表达和优化程序。AscendNPU IR 是华为基于 MLIR 生态构建的昇腾硬件抽象层，其方言工作在编译器中端。

参考官方快速入门中的 VecAdd 示例，探索 MLIR 中端逐层降低的过程：

- [AscendNPU IR VecAdd 快速入门](https://ascendnpu-ir.gitcode.com/zh_cn/sources/introduction/quick_start/examples_zh.html)
- [毕昇编译器](https://www.hiascend.com/cann/bisheng)

该部分留给同学自行探索。环境配置遇到困难时，可以阅读文档、理解方言设计差异，并在报告中记录探索过程。

## 作业完成要求

以一个简单的 C/C++ 源程序为例，例如本文末尾的阶乘或斐波那契程序。完成一个即可；多个内容重复的示例不会得到更高分数。利用编译器命令行选项取得各阶段输出，并研究输出与源程序之间的关系。

撰写符合科技论文规范的调研报告，至少包含题目、摘要、关键词、引言、工作与结果、结论和参考文献。文字、图和表应符合格式规范。报告必须提交 PDF，建议使用 LaTeX：

- [课程提供的 Overleaf 模板](https://www.overleaf.com/read/hnsjbjyknbdj)

两人共同完成并提交一份报告即可。报告开头要清楚说明两人的分工；两位组员都必须在小雅平台提交报告，否则无法评分。

基本要求部分应简洁明了，尤其是讲义已经覆盖的内容；自由探索部分可以详细展开。建议通过修改程序、调整调试或优化参数（包括自动并行化选项）等方式观察各阶段输出的变化，而不是把报告写成重复讲义的“命题作文”。

## 示例程序

### 阶乘

```cpp
int main()
{
    int i, n, f;

    cin >> n;
    i = 2;
    f = 1;
    while (i <= n)
    {
        f = f * i;
        i = i + 1;
    }
    cout << f << endl;
}
```

### 斐波那契数列

```cpp
int main()
{
    int a, b, i, t, n;

    a = 0;
    b = 1;
    i = 1;
    cin >> n;
    cout << a << endl;
    cout << b << endl;
    while (i < n)
    {
        t = b;
        b = a + b;
        cout << b << endl;
        a = t;
        i = i + 1;
    }
}
```
