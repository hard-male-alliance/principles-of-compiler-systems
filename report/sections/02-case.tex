\section{研究对象与分析方法}
\label{sec:case}

\subsection{案例程序与语义范围}

研究对象读取整数 $n$，计算
\[
b=\min(10,\max(0,n)),\qquad F(b)=\prod_{k=2}^{b}k,
\]
并输出 $F(b)$ 与一个换行，随后以状态 0 退出。空乘积定义使 $F(0)=F(1)=1$；上界 10 保证结果不超过 3,628,800，因而实际执行路径上的乘法均处于 32 位有符号整数范围内。清单~\ref{lst:sysy} 保留夹取、循环携带状态和外部调用三类与后续分析直接相关的结构。

\begin{center}
\begin{minipage}{0.92\linewidth}
\begin{lstlisting}[language=C,caption={SysY 案例的语义核心。},label={lst:sysy}]
int clamp_input(int x) {
  if (x < 0) return 0;
  if (x > 10) return 10;
  return x;
}
int factorial(int n) {
  int r = 1, k = 2;
  while (k <= n) { r = r * k; k = k + 1; }
  return r;
}
int main() {
  int r = factorial(clamp_input(getint()));
  putint(r); putch(10); return 0;
}
\end{lstlisting}
\end{minipage}
\end{center}

分支、循环和三个自定义函数足以暴露控制流、数据流、调用约定及跨对象符号解析。数组、递归、浮点和动态存储不属于分析范围。C 观察形态与 SysY 形态采用相同算法，其中 C 文件以对象式宏 \code{FACTORIAL\_LIMIT} 表示上界，并显式声明输入输出函数；该变体用于观察预处理和 Clang 生成产物，SysY 形态用于定义参考语义。

\subsection{工具链、目标平台与观测方法}

实验使用 WSL Linux 上的 Clang/LLVM 18.1.3，目标三元组为 riscv64-unknown-linux-gnu，指令集为 RV64GC，ABI 为 LP64D。RV64 程序通过 QEMU 用户态模拟器执行。完整生成命令和运行协议作为补充工件提供，正文仅报告影响结果解释的配置与计数口径。结构计数覆盖完整模块：IR 指令不含标签、声明和元数据；汇编近似指令行排除标签及大多数指示符，但保留伪指令；文件大小采用文件系统记录的磁盘字节数，而非 \code{size} 的节内容合计。

分析按图~\ref{fig:pipeline} 的观测点进行。每个阶段比较输入与输出表示，追踪上下界判断、循环累乘、函数调用及换行常量四项语义事实，并记录新增的类型、控制流、目标约定或地址信息。行为验证使用 $-3,0,1,5,10,20$ 六个输入，覆盖负数夹取、零次循环、多次迭代、最大未夹取值和上界夹取。
