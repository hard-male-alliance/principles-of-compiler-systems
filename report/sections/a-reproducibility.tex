\section{紧凑复现说明}
\label{app:repro}

本文观测环境为 WSL Linux 上 Clang/LLVM 18.1.3；目标为 64 位 RISC-V Linux GNU 环境，ISA 为 \code{rv64gc}，ABI 为 \code{lp64d}；完整目标三元组见后述命令。使用以下最小观察流程即可分别停在主要边界；路径按本仓库布局书写，省略只影响输出文件名的参数。

\begin{lstlisting}[language=bash,numbers=none]
# Preprocessed C and typed AST
clang -E preflight/src/bounded_factorial.c -o bounded_factorial.i
clang -Xclang -ast-dump -fsyntax-only preflight/src/bounded_factorial.c

# LLVM IR and RV64 assembly observation points
clang --target=riscv64-unknown-linux-gnu -march=rv64gc -mabi=lp64d \
  -S -emit-llvm -O0 preflight/src/bounded_factorial.c -o factorial-O0.ll
clang --target=riscv64-unknown-linux-gnu -march=rv64gc -mabi=lp64d \
  -S -emit-llvm -O2 preflight/src/bounded_factorial.c -o factorial-O2.ll
clang --target=riscv64-unknown-linux-gnu -march=rv64gc -mabi=lp64d \
  -S -O2 preflight/src/bounded_factorial.c -o factorial-O2.s

# Assemble the authored RV64 text, then inspect instead of inferring
clang --target=riscv64-unknown-linux-gnu -march=rv64gc -mabi=lp64d -c \
  preflight/asm/bounded_factorial_rv64gc.s -o asm.rv64.o

# Inspect, rather than infer, object and executable structure
llvm-readelf -h -S -s -r bounded_factorial.o
llvm-objdump -dr bounded_factorial.o
llvm-readelf -l bounded_factorial
llvm-objdump -d bounded_factorial
\end{lstlisting}

行为检查向每个实现分别输入 \code{-3, 0, 1, 5, 10, 20}，逐字节比较标准输出并检查退出状态。计数规则为：IR 指令不含标签、声明和元数据；汇编“近似指令行”排除标签及大多数指示符，但仍可能含伪指令；大小取文件系统记录的磁盘字节数，不与 \code{size} 的节内容合计混用。复现者应先核对完整版本字符串、ELF 头的机器/类型、RISC-V 属性和程序头，不能仅凭文件扩展名或驱动选项推断目标与链接形态。
