\section{可复现实验步骤}
\label{app:reproducibility}

权威流程在 Ubuntu Linux 上执行。进入 \texttt{preflight/} 后依次运行：
\begin{lstlisting}[language=bash]
cmake --preset ci
cmake --build --preset ci --target verify
ctest --preset ci --output-on-failure
\end{lstlisting}
配置输出必须显示 Clang、\texttt{riscv64-linux-gnu-gcc} 和 \texttt{qemu-riscv64} 的实际路径；缺少交叉工具时，RV64 执行测试不会被创建，不能解释为通过。

主要生成物位于构建树的 \texttt{generated} 子目录，包括预处理文件、AST JSON、源码生成的 LLVM IR/RV64 汇编、三份 RISC-V 对象、重建运行时，以及 source/IR/asm 三个静态可执行文件。测试驱动版本化保存五组向量与黄金输出，另外两个检查脚本保存流水线与 MLIR 的结构断言。

受控优化对照采用同一个 Clang 18.1.3 和声明注入：
\begin{lstlisting}[language=bash]
clang -x c -include preflight/include/sysy_builtin.h \
  -S -emit-llvm -O0 preflight/src/compiler_tour.sy -o tour.O0.ll
clang -x c -include preflight/include/sysy_builtin.h \
  -S -emit-llvm -O2 preflight/src/compiler_tour.sy -o tour.O2.ll
\end{lstlisting}

论文使用仓库内 Springer \texttt{llncs} 2.26 类，通过 \texttt{cd report \&\& latexmk -r latexmkrc main.tex} 构建。最终复核同时检查 LaTeX 日志、PDF 文本提取、字体嵌入和逐页渲染；仅看到非零页数不代表排版正确。
