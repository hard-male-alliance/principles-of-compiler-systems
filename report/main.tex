\begin{abstract}
本文以一个覆盖算术、赋值、条件分支、循环、函数调用与数组访问的 SysY 程序为共同研究对象，设计从预处理、编译、汇编到链接的端到端观察实验，并分别以 LLVM 中间表示（LLVM Intermediate Representation, LLVM IR）和 RISC-V 汇编重写其语义。研究采用“同一输入、同一可观察输出、逐层保存制品”的验证原则，将程序退出状态与标准输出作为端到端判据，同时通过控制流图和关键指令序列解释源级结构如何降低。进阶部分以多级中间表示（Multi-Level Intermediate Representation, MLIR）的方言转换和渐进式降低（progressive lowering）为分析主线，规划对 VecAdd 示例的逐层观察。当前稿为可复现实验协议与论文骨架；凡依赖实际运行的数据均明确标为待测，不以预期值替代观测值。

\keywords{编译流水线 \and LLVM IR \and RISC-V \and MLIR \and 渐进式降低 \and 可复现性}
\end{abstract}
